# First operational Control Centre

Run `npm run build:web`, then `npm run control-centre`. Open the printed `http://127.0.0.1:8788` address. The dashboard uses the existing Business 001 local store; starting it idempotently enables research's `web.read` and Delivery's local `artifact.release` and cancels the superseded v1 placeholder job. It does not start work automatically. One runtime/server process must own this file; concurrent processes on one store are unsupported.

On Businesses, supply genuine source material and a stable attempt identifier. Preparation creates five dependent jobs. Run each eligible job from Jobs. Model execution is disabled by default. Explicitly set `HQ_ENABLE_MODEL_EXECUTION=1` and provide `OPENAI_API_KEY` in the server environment to allow paid model calls. No key appears in browser configuration. Model calls keep existing exact nanodollar accounting and USD per-job admission limits. GBP allocation remains metadata, without FX or an aggregate USD budget claim.

Research can read public static textual web content. Sources and artifacts are untrusted reference data. Knowledge is explicitly unverified; completion of a knowledge/QA job does not constitute human validation. Inspect QA and its source chain before granting Delivery's exact artifact release. Resume the granted operation from Jobs. Its result is a local delivery packet referencing those reviewed artifacts. Customer contact, deployment, payment confirmation and revenue recording remain manual and are not implemented by this UI.

The backend has a single serialized save boundary. Outputs are created atomically with completion, and dependencies require both completion and the reserved runtime output artifact ID. Source artifacts are linked into output provenance. Immutable IDs conflict on altered input. Optional durable sections preserve existing v1 files. Ordinary Money and historical event payloads are unchanged; new fact types are additive. JSON transports bigint as decimal strings; durable storage uses the existing tagged bigint codec (now supporting signed artifact data).

SSE sends a scoped authoritative snapshot immediately on connection and after successful saves, plus visible heartbeat frames. Every reconnect rehydrates; event replay is unnecessary because these are complete projections. No frontend operational state lives in localStorage. One EventSource is retained. Lost/stale transport shows unknown room activity and disables mutations. Restored running executions without live ownership show interrupted; they are not automatically retried. Pending exact approvals can resume safely after restart. Tool dispatch is labelled tool-use, not proof of success; a failed/interrupted job is never displayed as completed merely because a tool began.

The room separates static floor/walls and reusable original workstation/agent SVGs from runtime-derived labels. Only proven live working/tool-use indicators pulse; no random walking, simulated work, shipped crates, customers, revenue or emergency-stop control. Completed and cancelled labels describe the latest assigned job, not agent employment state. Desktop uses five stations; mobile uses a compact two-column room.

The server is a **local operator surface**, bound to IPv4 loopback. It validates Host and Origin, uses a HttpOnly SameSite=Strict session cookie, rejects cross-origin mutations, bounds request bodies and slow SSE clients, and filters business scope before transmission. Anyone able to directly access the trusted local operator endpoint can obtain a session; this is not remote/multi-user authentication. Do not expose it through a proxy without adding real operator identity/authentication. The configured allowlist currently contains Business 001; the projection/transport supports separate allowed businesses.

`web.read` allows public HTTP(S), standard ports, no credentials/cookies, bounded identity-encoded responses, supported text MIME types, an overall DNS/request/body timeout and cancellation. Every redirect is validated and resolved independently. Every resolved address must be public; the socket connects directly to the selected validated address while retaining Host and TLS SNI/certificate validation. No second ambient lookup can rebind it. Private, loopback, mapped/local IPv6, link-local, metadata, CGNAT and reserved/documentation space fail closed. It does not execute JavaScript or claim browser-rendered content. Production uses built-in Node HTTP/TLS; deterministic tests inject DNS and HTTP, never external network.

Screenshots/results live in ignored `apps/control-centre/.local/smoke/`.
